About Me

With 13+ years of experience in .NET and Full Stack development, I specialize in modernizing legacy VB6, Classic ASP, and monolithic .NET codebases into modular, cloud-ready platforms. I architect solution blueprints, define migration roadmaps, and ensure every rewrite introduces measurable gains in reliability, performance, and observability.

My toolkit spans Factory, Singleton, CQRS, Domain-Driven Design, and Unit of Work patterns, enabling clean separation of concerns and testable modules. I routinely pair these patterns with microservices, Kafka-driven messaging, and secure Auth0 implementations to future-proof enterprise systems.

I've successfully modernized legacy applications, including upgrading Angular from v5 to v18 and migrating entire systems from VB6/Classic ASP to modern .NET Core + Angular architectures. These transformations significantly improved performance, security, and maintainability.

Currently driving AI RAG (Retrieval-Augmented Generation) systems using LangChain, Qdrant, MongoDB, Redis, and Python while leveraging ChatGPT, Azure OpenAI, Cursor AI, and GitHub Copilot for documentation automation, design validation, and rapid code spikes.

As a people-first leader, I mentor engineers, run Scrum ceremonies, manage stakeholder expectations, and maintain delivery cadence across distributed teams—all while keeping architecture guardrails and engineering excellence front and center.
