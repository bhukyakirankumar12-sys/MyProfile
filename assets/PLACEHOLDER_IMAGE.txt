PLACEHOLDER IMAGE INSTRUCTIONS
==============================

The website expects a profile photo at: assets/profile-photo.jpg

If the image is not found, the website will automatically use a placeholder.

To add your profile photo:
1. Save your photo as "profile-photo.jpg" in this assets folder
2. Recommended size: 400x400px or larger (square aspect ratio)
3. Supported formats: JPG, PNG, or WebP
4. Keep file size under 500KB for best performance

The image will be displayed as a circular profile picture in the Hero section.
