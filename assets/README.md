# Assets Folder

This folder contains:
- `profile-photo.jpg` - Your profile photo (replace with your actual photo)
- `resume.pdf` - Your resume PDF file

## Instructions

1. **Profile Photo**: 
   - Add your profile photo as `profile-photo.jpg`
   - Recommended size: 400x400px or larger (square aspect ratio)
   - Formats: JPG, PNG, or WebP

2. **Resume PDF**:
   - Add your resume as `resume.pdf`
   - The file should be named exactly `resume.pdf`
   - Make sure the file is optimized for web (under 2MB recommended)

## Current Placeholder

The website uses a placeholder image if `profile-photo.jpg` is not found. Make sure to replace it with your actual photo for the best presentation.
